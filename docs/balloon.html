Play DOOM over the balloon link

The payload runs the real DOOM engine. Each frame is encoded the way the flight code does it, sent through a simulated radio link, and decoded the way the ground software does it. Click the ground screen and your keys travel back up as Spacecraft Command Format packets.

Transmit and receive setups

The balloon's TT&C radio switches one antenna between its transmit and receive chains. The ground receiver is read from DOOMflow.grc as committed. The bench paths carry payload frames before the radio exists.

Repositories

Every UVic Satellite Design repository is a submodule under uvsd/, pinned to the commit below; the DOOM balloon's are the ones this page runs. node tools/uvsd.mjs setup fetches SDKs and dependencies; node tools/uvsd.mjs test builds and tests every repository with its own CI commands.
